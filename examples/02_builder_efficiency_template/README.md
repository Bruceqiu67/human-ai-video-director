# 案例二：《用 Builder 提高办公效率》SaaS 自动化工具宣传片模板

## 案例背景
针对效率工具、SaaS 平台或 AI Agent 产品的标准 5 幕短视频模板：
- **Act 1（机械内耗）**：重复琐事吞噬时间；
- **Act 2（认知跃迁）**：引入自动化外挂；
- **Act 3（流程实战）**：节点拖拽 10 秒流转；
- **Act 4（黄金公式）**：节点化 / 规则化 / 标准化；
- **Act 5（立即行动）**：变身超级个体。

## 运行方式
```bash
python -m studio audio build --project examples/02_builder_efficiency_template
python -m studio prompt generate --project examples/02_builder_efficiency_template
```
